🤖 AI Research Agent
An intelligent AI-powered research assistant built with Python, Streamlit, OpenAI, and Google Gemini that automatically researches any topic, gathers information from multiple sources, generates detailed reports, and exports professional PDF documents.

🚀 Features
🔍 Smart Research
Automated web research on any topic
Multi-source information gathering

🛠️ Technology Stack
Python
Streamlit
OpenAI API
Google Gemini API
BeautifulSoup4
Requests
ReportLab
Python Dotenv

📦 Installation
pip install streamlit google-generativeai openai python-dotenv requests beautifulsoup4 reportlab
⚙️ Environment Setup


▶️ Run Application
streamlit run app.py
